# CCSU-Campus-Information-App
For this project, I created a CCSU information app using Python and Tkinter. I wanted to make a simple application where students could click different buttons to view school information.

**What the app includes:**
Fall 2026 academic calendar
Campus building information
Faculty information
School of Business departments
MIS Department courses
CCSU logo and application layout

**#What I learned:**
Creating a GUI using Tkinter
Using buttons and functions
Reading CSV files with Pandas
Displaying information using labels
Adding and resizing images using Pillow (PIL)
